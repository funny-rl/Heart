# Security policy

## Supported versions

HEART is a research preview. Security fixes target the current 0.1 release line.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| Earlier or unreleased revisions | No |

## Reporting a vulnerability

Use GitHub private vulnerability reporting for the official repository when it
is available. Include the affected version or commit, impact, reproduction
steps, environment details, and any proposed mitigation.

Do not disclose exploit details in a public issue. If private reporting is not
available, contact the maintainer through the private channel published on
their GitHub profile and initially share only a request to establish a secure
reporting channel.

The maintainer will acknowledge the report, assess affected versions, and
coordinate remediation and disclosure. Response and release timing depend on
severity and the validation needed for a safe fix.

Incorrect Hearts behavior, strategy quality, performance regressions, and
research-validity concerns are ordinary correctness reports unless they also
create a confidentiality, integrity, or availability risk.
